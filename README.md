# Cybersecurity Learning Journey

Repositorio donde documento mi aprendizaje en ciberseguridad, enfocado en:

- (DFIR) Análisis de incidentes 
- SOC (Security Operations Center)
- (CTI) Threat Intelligence
- (MA) Malware Analysis
- Uso de MITRE ATT&CK

## Contenido

- Sherlocks (Hack The Box)
- Análisis de logs
- Investigación de ataques reales

## Objetivo

Desarrollar habilidades prácticas en detección, análisis y respuesta a incidentes de seguridad.
